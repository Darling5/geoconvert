# v1.5.10 — 3D 视图滚轮缩放减速至 1/5，操作更稳

## 优化 / Improved

**中文：**

- **3D 视图缩放减速**：「3D 预览」页与坐标转换页 3D 地球的滚轮缩放速度降为原来的 1/5（Cesium 默认偏快，近距离观察模型时容易一滚就飞过头），右键拖拽缩放、触控捏合同步放缓，微调更精准

**English:**

- **Slower zoom in 3D views**: mouse-wheel zoom in both the "3D Preview" page and the Coordinate page globe is slowed to 1/5 of the previous speed (Cesium's default is too fast for close-up model inspection), with right-drag zoom and pinch zoom slowed to match for finer control
